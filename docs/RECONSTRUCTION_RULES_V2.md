# 建筑重建与验证规则（V2）

> 历史 V2 记录。当前独立脚本、固定 20 栋训练样例以及最新限制，请以 [BUILDING_RECONSTRUCTION_ALGORITHM.md](BUILDING_RECONSTRUCTION_ALGORITHM.md) 为准。本文件下方“三个新版模型通过”仅描述之前保存的 V2 产物，不能代表后续脚本版本。

目标：尽可能贴合原始点云的建筑轮廓、局部屋面和立面结构。结构简洁只在不损失有证据的几何时才可作为优化目标。

当前实现：`scripts/buildingworld/reconstruct_detail.py`。可执行验证：`scripts/buildingworld/validate_detail.py`。阈值配置：`docs/validation_rules.json`。旧的 `reconstruct_baseline.py` 仅保留为对照，不代表当前规则。

1. **观测优先于建筑先验。** 保留有点支持的凹角、退进、凸出、局部降坡、屋脊变化与屋顶突出物；不得用最小外接矩形替换有可靠边界证据的真实轮廓。不得因占总点数比例小，就删去一个完整局部构件。
2. **屋面必须有局部作用范围。** 高低不同的近乎平行屋面属于不同空间分区，不能把一个平面无限延伸到整栋楼。两侧坡面应在实际交线上连接；高度不连续处应补真实高度的竖直过渡面。
3. **立面按观测分段推断。** 首先用立面点确定各墙段的位置和范围。凹角有上下墙面点支持时，将其延续为凹入立面；遮挡处才以局部竖直、共面和相邻轮廓连续性补齐。多个扫描带覆盖同一墙段且位置接近时，应拟合带不确定性的墙面，而不是编造多层墙。
4. **不臆造不可观测细节。** 本批数据能支持墙体轮廓与一些屋顶构件，不能据此确定门窗、阳台、材质和装饰。屋顶突出物可按观测范围形成几何实体，但其“烟囱/设备”等语义未确认。没有证据的地面高度仍须标记为推断。
5. **全部点参与主验证。** 法向和局部平面筛选仅用于发现结构，不能从最终点到网格统计中排除难点。报告平均、中位数、P95、最大值和超阈值点数；不得只报告主屋顶内点。
6. **逐结构验证。** 每块受支持屋面、屋顶小构件和每段观测立面单独计算覆盖率。任一局部失败，整体模型就不能标记为通过，即使总体平均误差很低。
7. **轮廓单独验证。** 用未经轮廓简化的点云 alpha 边界检查投影 IoU、双向边界误差及无观测支持的多填面积；不能只检查点被外接矩形包含的比例。
8. **闭合只是必要条件。** 同时检查开放边、非流形边、退化面、正体积；额外用 Blender 三角网格 BVH 检查非相邻三角面重叠候选，并交叉核对点到表面距离。
9. **区分观测与补全。** 反向“网格采样点到输入点云”距离按屋面、观测立面区域、遮挡立面、屋顶侧壁和推断底面分开报告。遮挡造成的缺点不等于没有墙，不能为了降低反向距离而删掉合理补全部分。
10. **验证阈值不迁就当前结果。** V2 的阈值是当前输入坐标下的工程门槛，保存在 JSON 中，不能为使某个样例通过而临时放宽。迁移到不同单位、密度或噪声的数据时，应先重新标定；这些门槛并非官方评测协议。

当前门槛：全点 P95 ≤ 0.15，0.15 范围内全点比例 ≥ 95%；每屋面和每观测立面覆盖率 ≥ 90%；轮廓双向 P95 ≤ 0.20、IoU ≥ 0.96、无支持的多填面积比例 ≤ 1%；拓扑闭合且正体积。长度均为输入坐标单位，当前仅在显示时暂按米处理。

V2 已把三个旧模型作为负对照：它们虽然闭合，仍因局部结构或轮廓失配而未通过。当前三个新版模型通过这些工程门槛，但依然不是具有网格真值验证的最终建筑模型。
