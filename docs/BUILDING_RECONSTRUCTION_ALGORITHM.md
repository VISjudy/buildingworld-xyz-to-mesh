# 从单栋 XYZ 点云恢复建筑：规则、算法逻辑与评分设计

当前版本：0.5.1，日期：2026-09-21。独立入口为 `pointcloud_to_mesh.py`，本地网页为 `webapp/server.py`。本文是后续迭代的统一算法说明；`RECONSTRUCTION_RULES_V2.md` 保留 V2 的验收原则，数值门槛保存在 `docs/validation_rules.json`。历史 0.4.1 结果留在文末。

## 目标与输入输出

输入：单栋建筑、以 Z 为竖直方向、只有 X/Y/Z 三列的点云。输出：源坐标下的 OBJ 建筑表面网格，包括尽可能由观测支持的屋面分片、屋脊/谷线/檐口、立面和补全底面。输出同时保存 JSON，记录局部平面、支持点数、墙段证据、临时底高、拓扑检查和适用限制。

优先级：**观测几何和结构边保真 → 局部拓扑与实体合理性 → 面片/顶点简洁程度**。不能为了减少面数而抹平有点云支持的凹角、退进、局部高差或小构件。也不能把扫描噪声逐点转为锯齿网格。

当前是确定性的几何规则原型，不是已训练的神经网络。“蒸馏”为脚本是把这些规则凝练成可复现代码。目前已经得到不依赖 Blender 和模型权重的单文件命令行程序；第三方数值库仍需安装。

## 对齐最终评测

用户指定：`FINAL SCORE = 0.6 × CD + 0.4 × ECD`。若使用原始距离误差，目标是最小化该值。NC、V_Ratio、F_Ratio 单独报告，不擅自添加到这条官方加权公式中。

**最终评测必须是预测网格与真值网格的比较。** 当前没有下载真值，也没有官方采样/归一化代码，因此 JSON 中的 CD、ECD、NC、V_Ratio、F_Ratio、FINAL SCORE 均为 `null`。不得把输入点云到预测网格的距离当作它们。

用于准备评测器的明确建议如下，实际应由官方实现覆盖：

1. 从预测和真值网格按表面积均匀采样 `S_pred`、`S_gt`。一种常见的非平方、双向平均形式是：
   `CD = 0.5 × [mean_{p∈S_pred} min_{q∈S_gt} ||p-q|| + mean_{q∈S_gt} min_{p∈S_pred} ||q-p||]`。
   这只是待确认的实现约定；官方可能使用平方距离、不同的双向求和系数或归一化，不能自行冒充官方定义。
2. 从真正的结构边按长度均匀采样 `E_pred`、`E_gt`，用相同双向距离形式计算 ECD。屋脊、谷线、檐口、墙体折角、高差连接边是需要保留的几何证据。共面三角片内部对角线不应因为导出三角化而被自动当作结构边；结构边判定的二面角门槛、边界边是否纳入、底面边是否纳入都需要对齐官方实现。
3. NC 比较对应表面位置的法向。是否取绝对点积、是否双向平均、法向是否朝外必须固定。当前只把法向一致性、面朝向与邻接关系作为几何质量约束。
4. V_Ratio、F_Ratio 通常需知道预测和真值的计数方向与面类型。比较前必须明确 polygon 与 triangle 的口径；目前仅报告预测网格的实际 V/F，不能伪造比值。
5. 坐标变换必须由输入到输出保持一致；不得分别对预测和真值自由缩放来制造低误差。若协议要求归一化，应使用同一已知变换。

### 算法设计如何体现 0.6 / 0.4

CD 对应整体屋面、立面位置与完整性；ECD 对应屋脊、檐口、凹角和高差边的位置、方向与连接关系。因此采用“**局部平面 + 边界/交线 + 立面约束 + 闭合装配**”，而不是只追求平滑表面或全局点距离最小。

有真值时，在独立验证集上，以真实 `0.6 CD + 0.4 ECD` 选择参数和候选模型，不能用测试真值调参。阈值、平面合并、轮廓简化与细节保留都应做消融实验。

没有真值时，可建立 `0.6 L_surface_observed + 0.4 L_edge_observed` 的观测代理目标，但这**不等价于官方分数**：前者只能约束可观测部分，后者的边证据还需要从点云中估计。当前 0.5.1 版尚未实现这个统一代理目标的全局优化；实际执行的是平面拟合、局部支持投票和逐项验收。禁止宣称脚本已经直接优化了官方 FINAL SCORE。

后续边项应同时约束点云边界、相邻平面交线和有立面支持的转角；每条边记录支持范围和不确定性。对弱观测边允许多个合理假设，不把一条臆造的长直边压过已有的局部轮廓。

## 当前算法步骤

### 1. 输入检查与局部坐标

- 检查恰好三列、有限数、至少 20 个点，以及 XY 非退化。
- 由 XY 最小旋转矩形确定一个分析方向；**该矩形仅提供方向，不作为输出建筑轮廓**。
- 将 XY 旋转到 UV，Z 保持不变。所有输出顶点再做逆旋转，保留原始输入坐标与尺寸。
- 当前参数按这批接近米量级的局部坐标设定；其他单位、大地坐标或明显不同的密度需要先标定。暂未实现通用尺度自适应。

### 1a. 保守噪声处理（0.5.1）

- 默认 `--noise conservative`；`--noise off` 保留所有输入点。过滤不移动或平滑任何点。
- 对每点计算最多 12 个邻居的平均距离 `d`。同时满足三项才排除：`d > 全局中位数 + 6 × max(1.4826 MAD, 中位数的10%)`；`d > 邻居 d 中位数的 2.5 倍`；最近邻距离 `> max(全局最近邻距离中位数的3倍, 0.05)`。
- 这是保守的孤立点启发式，不是噪声真值标签。不能保证清除面内扰动、成片噪声或扫描偏差，也可能误判孤立但真实的细节。连贯的小构件不能因点数少就自动删除。
- 同名 JSON 的 `noise_diagnostics` 记录输入/使用/排除数量、原始点索引和规则。网页叠加可标红排除点。
- 最终验证始终读取未过滤的原文件；不允许靠删除难点降低主验收误差。基准面若受低回波影响，优先传入可信底高，不把稀疏地面一律视为噪声。
- 孤立点检测与常见邻域统计滤波有关，但本实现的三重条件更保守，并非直接调用 Open3D。参考：[Open3D 官方离群点处理文档](https://www.open3d.org/docs/release/tutorial/geometry/pointcloud_outlier_removal.html)。

### 2. 局部法向与表面候选

- 在 16 邻域做 PCA，最小特征值对应方向估计局部法向；最小特征值/特征值和作为曲率指示。
- 当前屋面发现条件：`|nz| > 0.50`、曲率 `< 0.05`、Z 高于输入的 25% 分位数。
- 这些条件仅用于发现平面，不能用于从最终主验证中排除不易拟合的点。陡屋顶和低位屋面可能被漏检，是需要检查的限制。
- RANSAC 内点还要求估计点法向与候选平面法向的绝对点积 `> 0.94`，避免用方向不一致的点凑出弱支持坡面。它仍会受边缘法向误差影响，已在两处复查样例观察到贴合误差变差，不能宣称普遍改善。
- 合并方向差小于 7° 的近共面候选，还须满足新支持点相对已有面的残差 P90 ≤ 0.12，以及两面支持点联合拟合后的残差 P95 ≤ 0.10。高度跳变证据不符合时保留分面。

### 3. 分片屋面与小构件

- 对候选点做确定性 RANSAC，拟合 `z = a u + b v + c`，再最小二乘细化。
- 当前阈值为 0.065 个坐标单位；每阶段 650 个随机三点假设，最多提取 12 个平面；最少支持为 `max(20, 1.2% 屋面候选点数)`。
- 用与平面残差小于 0.10、且接近该平面支持区的点扩展其局部范围。
- 用二维 Delaunay 三角形外接圆半径筛选构建 alpha 区域，提取局部面域，而不是将平面无限延伸。
- 对以平顶为主的样例，额外寻找高于主屋面 0.16 的空间连通点团；至少 8 个点、局部跨度合理时保留为屋顶突出物。顶高和范围来自点云，竖直侧面是补全。当前这一补充仅适用于主平屋顶，不能认为所有坡屋顶烟囱都已恢复。
- 当前仍有最小区域面积/宽度筛选，所以极小或极窄结构可能遗漏。后续应改成基于密度、噪声和结构连续性的置信度，而不是简单面积阈值。

### 4. 建筑轮廓与立面证据

- 使用全部点的 XY/UV 投影建立 alpha 轮廓，默认半径 0.60，先保留凹角，再有限简化（0.20）。
- 只有接近正交、由邻边支持的短采样圆角才进行方向规整，斜向边应保留。当前规整启发式仍需视觉检查，不能保证真实斜角不会被误改。
- 立面候选为近水平法向、低曲率且接近主 UV 轴的点；通过坐标集中带发现墙段，并记录其他方向范围和 Z 范围。
- 相近且范围高度重叠的扫描带合并成同一墙面估计，并记录位置不确定性。真正位置分离的退进墙段分别保留。
- 优先以墙段定位轮廓；未见墙的侧面才由屋顶边界和相邻连续性推断。不能把凹角填成矩形。
- 保留 alpha 轮廓的所有有效连通区域，包括各自内环，不再只留下最大部分。每个区域分别完成屋面、墙体和底面；没有证据时不强行连接两块建筑。alpha 阶段小于 0.02 面积的碎片及部分小洞仍可能被滤除，需结合全点误差和未简化轮廓检查；复杂内院、悬挑、立面洞口尚未可靠解决。
- 若方向规整让环坍缩为不足三个点、面积近零或自交，回退到规整前的环；不得通过删除整个有效构件来规避异常。

### 5. 局部屋面分区与交线

- 对近乎平行、但高度不同的屋面，从各自局部支持区和墙体退进推断分区边界。
- 对不同坡向的相邻平面，计算准确交线形成屋脊/谷线候选。
- 同一候选平面的不同支持岛合为一个局部域，避免同一平面多次竞争。多层近似平行屋面加入其局部域边界，允许附楼在局部结束。
- 将边界和交线组成平面分区；区域内至少有 3 个有效屋面点时，按拟合平面标签投票。点数不足时，用代表点附近最多 24 个屋面观测，按 `1 / max(XY距离, 0.10)^2` 投票。突出物仅在自身支持区内覆盖主屋面。
- **已取消全局/局部最低平面包络选择。** 投票优先保留局部观测高度，但仍可能出现域界锯齿、弱支持平面延伸、窄结构遗漏和不正确高差连接。每个例子的误差与失败门槛必须保留。
- 当前平行判断及交线候选的坡度差门槛为 0.015（旧版 0.08），使低坡双坡屋顶也可生成交线。该值仍不是通用最优值；后续需要法向角度、邻接图、局部支持和连续性联合求解，限制外推距离。

### 6. 立面补全与闭合装配

- 屋面片共享的 UV 边界采用一致的顶点，连续屋脊共享同一空间边。
- 有屋面高差时增加竖直连接面，避免把低屋面整体抬高或把高屋面压低。
- 外轮廓沿已估计墙段方向向下补齐；无额外证据时以竖直墙体作为建筑先验。
- 默认底高为输入 Z 的 0.1% 分位数；这是接近最低回波的假设，不代表确认地面。可用 `--ground-z` 传入可信底高。
- 屋顶和底面采用 Earcut 三角化（支持内环），避免本批次 GEOS 约束三角化异常或卡住。线网使用 0.0001 精度；相同 XY 桶中相距小于 0.001 的数值重复点焊接；再分割共线边处理 T 形接点。复杂交汇仍有拓扑失败，必须报告，不能把“导出成功”标成“闭合合格”。
- 输出面组区分屋面、构件、立面补全、高差连接和推断底面。
- 若同一平面边出现三个以上邻接片，记录 `unresolved_partition_edges`，保留屋面候选而不臆造连接墙。网页/批次验证增加 `resolved_partition_adjacency` 门槛并强制失败。输出可供定位问题，不能称为完整闭合实体。
- 不生成没有点云依据的门窗、阳台、材质或装饰；仅依据屋顶不能唯一确定全部墙高。

## 验证规则

闭合只是必要条件，必须和观测贴合同时检查：

| 检查 | 当前工程门槛 |
|---|---|
| 全部原始点到网格表面距离 | P95 ≤ 0.15；距离 ≤ 0.15 的比例 ≥ 95% |
| 每个受支持屋面/突出物 | 距离 ≤ 0.15 的比例 ≥ 90% |
| 每段有观测的立面 | 距离 ≤ 0.15 的比例 ≥ 90% |
| 与未简化点云 alpha 边界比较 | 投影 IoU ≥ 0.96；双向边界 P95 ≤ 0.20 |
| 无支持的多填面积 | 占预测轮廓面积 ≤ 1%，支持带宽为 0.15 |
| 拓扑 | 零开放边、零非流形边、零退化面、正体积 |
| 轮廓完整性 | 不得仅验收最大连通块；全部观测轮廓参与比较 |

长度为输入坐标单位。阈值是当前批次工程门槛，不是官方标准，也不为了使本轮样例通过而放宽。最大距离、超阈值点数、每局部结构结果与失败原因必须保留。

网格采样点到输入点云的反向距离按屋面、观测立面区域、遮挡立面、屋顶侧壁和底面分组。遮挡缺点不等于墙体不存在，不能通过删除合理补全面降低反向距离。Blender 对本批次额外独立核对开放边、非流形边和体积；本轮没有完整自交检测，之前三个样例做过的交叠候选检查不代表这 20 栋也已通过。没有真值时，所有这些都是一致性诊断。

### 0.4.1 本轮实际结果
