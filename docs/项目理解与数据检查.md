## 1. 论文提供了什么

原文：`03935-AAAI26.HuangS-CV.pdf`，共 10 页；标题为 *BuildingWorld: A Structured 3D Building Dataset for Urban Foundation Models*，作者 Shangfeng Huang、Ruisheng Wang、Xin Wang，AAAI-26。

- PDF 第 3–4 页：数据汇集 44 座城市、约 500 万个 LOD2 建筑，覆盖约 21,718 平方公里。数据规模和全球覆盖描述的是完整 BuildingWorld，不等于当前本地的 7,475 个文件。
- PDF 第 4–6 页：以建筑模型为几何来源，使用 HELIOS++ 模拟机载激光扫描，模拟航线、遮挡、扫描角和密度；另有直接从模型表面采样的完整点云，采样密度为 30 点/平方米。模拟 ALS 和完整表面采样不能混为同一种输入。
- PDF 第 4 页：部分真实 ALS 与政府建筑模型存在位置或屋顶几何不一致，不能默认所有真实点云—网格配对都严格对齐。
- PDF 第 6 页：Cyber City 组合地形、道路/建筑轮廓、建筑、植被，支持生成不同场景及遮挡条件的数据。
- PDF 第 7 页：基准表 2 报告 PBWR、EdgeDiff、BWFormer，以 Building3D/Tallinn 的真实点云与人工标注考察模拟训练到真实数据的迁移。论文正文实际表格是三类方法，不应把摘要中的“五种方法”直接当作已有五个可运行基线。
- PDF 第 7 页：表 2 使用 ACO、角点/边的 Precision、Recall、F1；没有定义本项目给出的 `0.6 × CD + 0.4 × ECD` 评分。

论文是数据集与基准工作，不附带一个可直接把任意 XYZ 转成完整 LOD2 的统一重建算法。模拟到真实的实验支持特定条件下的迁移，不能推导出当前 4,000 栋都可准确重建。

核对过的官方来源：

- 项目页：https://szusic.github.io/BuildingWorld/
- 数据卡：https://huggingface.co/datasets/BuildingWorld/BuildingWorld
- 文档页：https://szusic.github.io/BuildingWorld/documentation.html

官方数据卡列有 Mesh、Simulated PC、Wireframe；当前本地未包含这些配套网格/线框。访问时 Documentation 仍是模板内容，Leaderboard 链接回到主页，因此未获得本项目 CD/ECD 的官方实现。没有下载完整数据集。

## 2. 本地全量审计

按用户指定：`xyz` 用作训练数据，`LiDAR_xyz` 用作测试数据。文件夹名字不能单独证明模拟/真实来源，当前没有来源城市或扫描参数的清单。

| 项目 | xyz | LiDAR_xyz |
|---|---:|---:|
| 文件数 | 3,475 | 4,000 |
| 总点数 | 37,871,627 | 45,957,741 |
| 每栋点数中位数 | 5,877 | 5,305.5 |
| 每栋点数范围 | 150–516,932 | 120–1,271,416 |
| 文本大小（十进制 GB） | 2.925 | 1.643 |
| 列数 | 全部 3 | 全部 3 |
| 解析错误/非有限数值 | 0 | 0 |
| 完全重复的额外文件 | 16 | 0 |

两个 ZIP 的文件数量、未压缩总大小与解压目录对应，都只包含 XYZ，没有隐藏的网格、法向、语义标签或评测脚本。未做 ZIP 全量 CRC 完整性校验。

坐标常有负 Z，XY 包围盒中心通常接近原点，符合经过局部坐标处理的数据表现；但没有变换矩阵或 CRS，不能确认具体中心化方式、真实单位和地面位置。不能用 Z=0 自动封底，也不能直接把 `zmax-zmin` 宣称为真实建筑高度。

抽样可视化发现多个点云有明显屋面与立面回波。例如 `LiDAR_xyz/10.xyz`、`1000.xyz`、`2000.xyz` 并不是仅有屋顶。抽样不能替代全量语义分类；目前文件没有屋顶/墙面标签。

异常实例：`data/inputs/xyz/844.xyz` 的 X、Y 跨度都为零；`data/inputs/xyz/981.xyz` 的空间跨度约为 0.0165 × 0.0123 × 0.0081 个坐标单位。它们需要隔离检查，不能自动当作有效建筑进入训练或批量重建。少数近乎平面的文件则可能只是平屋面，需要结合数据来源判别，不能一概删除。

**数据划分存在几何重叠，后续训练前必须检查。** 文件哈希在两组间没有相同项，但坐标变换后的点云仍可能是同一个样本。按相同点数、Z 跨度差小于 1e-7 且训练样本 XY 跨度大于 1 筛得 900 对候选；这不是 900 个已证实重复建筑。对前 10 对按原始点顺序做中心化和正交对齐，误差均约为 1e-9 或更小，确认至少这些对应项在旋转/镜像/平移意义下近乎相同。

示例：`data/inputs/xyz/884.xyz` 与 `LiDAR_xyz/11.xyz` 为 8,594 点，旋转对齐 RMSE 约 6.37e-10；`data/inputs/xyz/3307.xyz` 与 `LiDAR_xyz/28.xyz` 为 3,775 点，允许镜像的正交对齐 RMSE 约 4.13e-10。不能用当前目录划分直接证明模型对未见建筑的泛化。当前重建未训练，也没有使用这些匹配关系进行模型生成。

机器可读结果：`pointcloud_inventory.csv`、`data_summary.json`、`cross_split_overlap_check.json`；可复现脚本：`audit_data.py`、`audit_overlap.py`。

## 3. 本次 Blender 样例

仅输入 `LiDAR_xyz/10.xyz`、`1000.xyz`、`2000.xyz`，没有网格真值、建筑轮廓或人工屋脊。算法不是神经网络，也没有在测试集上训练；在每个输入上拟合几何属于本次无训练重建。

流程：

1. 24 邻域 PCA 估计法向，筛选倾向于屋面的局部平面点。
2. RANSAC 拟合 `z=ax+by+c`，再用最小二乘细化；拟合阈值为 0.10 个输入坐标单位。
3. 枚举候选平面子集，以截断残差和轻微复杂度惩罚选择主屋顶。主屋顶用平面下包络形成平屋顶/双坡等凸屋顶。
4. 从 XY 最小旋转矩形的方向及投影 0.2%/99.8% 分位数估计矩形建筑轮廓。这个矩形假设不能表达 L 形、内院、退台或附属建筑。
5. 平面交线形成共享屋脊；将外边界竖直延伸至临时底高，再补底面。
6. 底高取输入 Z 的 0.1% 分位数，只代表接近最低观测回波的高度，不证明那里是地面。
7. 检查边的双面邻接、欧拉特征、体积和 Blender 重开后的完整性。

| 输入 | 屋面数 | 顶点/多边形面 | 非流形边/开放边 | 屋面候选点竖向残差中位数/P95 |
|---|---:|---:|---:|---:|
| 10.xyz | 1 | 8 / 6 | 0 / 0 | 0.0232 / 0.0521 |
| 1000.xyz | 1 | 8 / 6 | 0 / 0 | 0.0125 / 0.0327 |
| 2000.xyz | 2 | 12 / 9 | 0 / 0 | 0.0189 / 0.5019 |

表中残差只针对经过筛选的屋面候选点，是同输入拟合诊断，不是完整点云误差、真值精度或 CD/ECD。单位为输入坐标单位；仅为 Blender 显示暂按米设置。小于 0.20 单位的屋面候选点占比分别为 100%、99.89%、91.18%。这些比例不会覆盖被法向筛选去掉的屋顶边缘、女儿墙或小细节。

2000 的主双坡屋顶已恢复，但另外一块约 0.5 单位高差的平行屋面未保留。10 和 1000 的平顶基线也未表达所有高处散点或局部细节。闭合只说明拓扑满足当前实体构建，不代表几何完全正确或达到官方 LOD2 质量。

另外试过 2、3、100、500，初版全平面下包络在多高度和复合屋顶上明显失配；这些旧探索输出移至 `work/legacy_output/lod2_xyz_baseline/exploratory`，不属于最终展示模型，不能用于评测提交。后续平面子集筛选修复了 2000 的主屋顶压低问题，但没有解决多体块建模。

## 5. 针对完整 LOD2 和评分的后续路线

完整目标应包含屋面分片、屋脊/谷线/檐口拓扑、外墙、必要的高度分区和封底。优先以“屋顶结构恢复 + 足迹/立面约束 + 地面推断 + 闭合网格装配”为路线，Blender 用于展示和网格校验。

当前先补足三项：非矩形轮廓与内院；不同高度屋面/附属体块的局部支撑区域；根据低位立面回波和建筑先验估计地面并输出置信度。不能把一个低屋面平面无限延伸到整个建筑。

只有屋顶且缺少地面、立面或外部高度信息时，同一个屋顶可以对应不同墙高；完整建筑不能从观测中唯一确定，应输出带假设的候选模型。当前样例的墙面回波降低了这种不确定性，但不能完全消除。

用户给定评分 `0.6 CD + 0.4 ECD` 若直接加权原始距离，则越低越好。正式评测前需拿到真值与实现，确认：距离还是平方距离、双向求和还是平均、坐标归一化、表面和边的采样数量/分布、哪些边算结构边、是否包含墙和底、NC 是否取法向绝对值、V/F Ratio 的方向及三角化规则。多边形面数与三角面数不能直接对比。

当前没有计算官方 CD、ECD、NC、V_Ratio/F_Ratio 或 FINAL SCORE。下载真值后应先核对建筑 ID 和坐标变换，再按原始建筑身份去重划分训练/验证/测试，最后比较结构恢复方案，而不是以三个展示样例推断全量精度。
