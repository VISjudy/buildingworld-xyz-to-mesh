# LoD2 Recursive Self-Improvement Harness：完整实验协议

版本：2026-09-21。本文保存用户已确认的完整研究设计。实现进度见 `prompt/registers/research.md`，不能将计划当作实验结果。

## 1. 目标和两个贡献

固定基础大模型，离线改进点云到 LoD2 Mesh 的算法代码、反馈策略和经验检索；不训练基础大模型。最终独栋 XYZ → 源坐标 OBJ、结构线框、质量报告程序无需调用大模型。只研究 LoD2。

贡献一是外部证据反馈设计：哪些几何、结构、拓扑、建筑规则与视觉证据，以及怎样的定位和表达，能帮助模型产生有效算法修改。外部程序计算分数，大模型不能自行给分。

贡献二是改进机制的共同演化：跨建筑总结有效和无效修改，演化反馈选择、视角、检索和候选策略，提高后续改进效率。代码多轮修改和保存经验本身不证明创新，必须通过受控消融和迁移验证。

## 3. 文献与建筑知识库

证据矩阵包含输入、输出、假设、监督方式、代码、权重、数据依赖、失败模式、复现成本、与本研究关系。重点：PolyFit、City3D、Point2Building、PolyGNN、BWFormer、PaCo、UniCo、BuildAnyPoint；补充 PBWR、EdgeDiff、GREO。机制方向：GEPA、Darwin Gödel Machine、HyperAgents。详见 `LITERATURE_REVIEW_RSI.md`。

完整 Mesh 方法进入主表，线框方法进入结构表；补面后参评须标明组合方法及适配成本。轮廓从输入估计；使用真值轮廓单列。代码存在、权重链接存在、下载成功、推理成功、公平复现是不同状态。不得直接比较不同数据集的论文分数。

知识三层：文献关系、可计算工程规则、实验经验。每条包括 ID、出处、适用条件、所需观测、硬/软约束、反例、算子、验证案例、状态/版本。

主题包括屋脊/谷线/檐口与交线，多高度/附楼/凹角/内院，局部平面支持与共享边，墙体竖直及闭合装配，稀疏/遮挡/法向不确定性，未知地面，以及保真—结构—复杂度取舍。正交/平行/对称是软先验；可靠观测可推翻。单栋经验先作假设，跨样本验证后再升级。每轮冻结知识版本。

## 4. 外部反馈

执行链：重建程序 → 固定外部评测器 → 反馈生成器 → 大模型修改候选 → 独立复测与接受/拒绝。

| 证据 | 计算 | 定位与解释 |
|---|---|---|
| 观测贴合 | 全部原始有限点的点面分布、P95、覆盖 | 坐标、点 ID、关联面、残差范围 |
| 方向 | 多尺度法向、平面夹角与置信度 | 坡向、稳定点覆盖、边缘不确定性 |
| 结构 | 屋脊、谷线、檐口、角点偏移/缺失/断连 | 边/面 ID、支持点、邻接关系 |
| 拓扑 | 开放边、非流形、退化、自交、朝向 | 可复现位置；未检查项目显式 NA |
| 建筑规则 | 连续、竖直、共面、复杂度 | 适用条件、例外、关联算子 |
| 开发真值 | Mesh、Wireframe 对比 | 补全错误及观测代理盲区 |

缺点不等于空空间。没有扫描轨迹时，不能将 Mesh→点云距离直接作为补全惩罚。全原始点诊断与去噪结果分开；低置信度边缘法向与稳定平面分别报告。开发可用真值反馈，最终推理只用允许输入。

固定渲染七视角：顶视、四侧视、两个斜视；点云叠加、深度、法向、残差及带 ID 的局部结构错误图。相机、尺度、材质、光照、色标一致。视觉解释不能替代几何指标；点云投影不是完整轮廓真值。

### 反馈消融 F0–F5

| 编号 | 条件 | 问题 |
|---|---|---|
| F0 | 无结果反馈，仅重试 | 重复生成收益 |
| F1 | 单一总分 | 标量能否指导修改 |
| F2 | 全局指标向量 | 指标分解作用 |
| F3 | 带结构定位文本 | 局部定位是否提高修复效率 |
| F4 | 同等证据的图像 | 空间可视化作用 |
| F5 | 文本+图像 | 模态互补 |

补充：纯错误/修改假设；全局/局部裁剪；固定/自适应视角；打乱位置、过时反馈、漂亮渲染负对照；精简证据/冗长日志。固定初始算法、基础模型版本、样本、候选次数；分别做同证据和同成本匹配。图像渲染实际消耗和视觉 Token 计入预算。

有效性看独立验证收益、有效修改比例、回归率、单位成本收益；不能让大模型自评代替实验。

## 5. 内层与外层

内层依次研究尺度/密度/噪声适配、非矩形支持域、多屋面/多高度、候选平面邻接与交线、共享顶点边装配、立面底面补全、复杂度控制。中间表示显式保存面、边、顶点和邻接。

候选记录：问题假设 → 外部证据 → 知识 ID → 补丁 → 预期收益 → 实际收益/回归。不得按建筑 ID 特判或放宽验收。

外层积累跨建筑结果，研究诊断排序、图像裁剪、知识检索、修改提议和实验选择。允许增加诊断工具，但固定数据、真值、最终评测定义、封存测试、验收和预算。评价器修复必须版本化，并统一重算所有比较版本。

关键迁移实验：将原始与演化后的 Harness 放回同一个初始算法，在新开发任务以同预算优化，比较最终质量、达到目标所需候选数、有效率/回归率和收益—成本曲线面积。不成立就只宣称算法优化/经验复用。

## 6. 统计、指标与验收

小试每条件 10 候选；完整实验 3 独立种子 × 每种子 30 候选。失败计预算。基础模型、版本、推理配置固定，记录 Token、时长、费用、超时、编译/运行失败与回滚。

逐栋记录；按城市做成组配对置信区间；没有城市标识时不得假装城市 bootstrap。全部失败纳入分母；不能仅统计成功结果均值。选择验证集是自适应开发数据，方案冻结后才开封测试。

完整 Mesh：CD、ECD、NC、V/F_Ratio、拓扑有效率、自交/退化、失败率、耗时/资源。结构表：角点/边 Precision、Recall、F1、位置误差。结构边去除共面三角化对角线。真值线框若只有屋顶，先明确定义屋顶评测域，不能直接惩罚推断墙边。

官方页面公开指标含义，但采样、归一化、边提取及加权尚未逐项核准。`0.6 CD + 0.4 ECD` 不标作本地官方复现分数。比赛上传仅有限外部验证，不接入自适应循环。

原始数据 `../dataset/`；加工数据 `../dataset/processed/<version>/`；中间运行 `work/experiments/2026-09-21/lod2-rsi-v001/`；可交付报告 `reports/<date>-<stage>/`。

每栋必须同图展示输入｜基准｜上一版｜当前，附叠加、残差、结构错误和两组指标差值。缺失明确写失败。展示平移不写回 OBJ。渲染 SHA 与评测模型一致。

验证包括已知几何距离/法向/边、开放边/反向/自交/漏屋面/屋脊错位注入、源坐标和 OBJ 重导入、三角化非结构边、冻结复现、异常与超时。未实现的检查显式列待办。
