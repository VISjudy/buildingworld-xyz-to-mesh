## 2. 筛选的数学定义

设原作者坐标下的 Mesh 包围盒对角线为 D，建筑高度为 H，最低顶点高度为 z₀。各阈值在对算法预测评分之前固定，真实与仿真使用相同无量纲立面门槛。GT 被用于数据质量筛选，这会造成选择偏差；不要将筛选后结果直接外推至原始总体。

### 2.1 输入与拓扑

- 同一城市/作者 split/建筑 ID 配对 XYZ（或安全读取的 numeric NPY）与有面的 OBJ。
- 点云必须为有限 Nx3。非法值直接失败，不静默删除。Mesh 必须有非退化高度与包围盒。
- 用每个原多边形的局部平面与 Earcut 三角化，保留面向和原多边形来源；三角化仅用于计算。
- 严格筛选要求闭合、朝向一致、三角形面积大于 1e-12 作者坐标单位平方。不对 GT 焊接、补洞、挤出或修补以使其过关。
- 此面积阈值是原脚本的数值条件，非跨尺度物理阈值；必须披露其潜在尺度影响。

### 2.2 主墙面与底面

三角片单位法向为 n，垂向范围为 [z_min, z_max]。主墙面同时满足：

1. |n_z| ≤ sin(10°)；
2. z_min ≤ z₀ + 0.1H；
3. z_max − z_min ≥ 0.25H。

底面候选满足 |n_z| ≥ 0.9 且 z_max ≤ z₀ + 0.05H。要求至少存在主墙面和底面，且 Mesh 满足上述闭合约束。当前程序没有屋顶语义分类真值，不额外声称做过逐面屋顶语义核验。

### 2.3 实际立面回波

对每个原始点计算到参考三角面的最近距离及最近面 ID。计为主墙面支持点需同时满足：最近片为主墙面、距离 ≤0.005D、点高严格处于该片垂向区间的 10%–90% 内部。这样避免仅贴近屋檐/底边的点被误算为立面回波。

有效支持要求：点数 ≥10；占全部原始点比例 ≥0.005；这些点的垂向跨度 ≥0.15H。另要求全部点到参考 Mesh 的距离 P95 ≤0.05D。这一几何近邻判据不能保证每面墙均被扫描，也不能代替逐点人工立面标签。

### 2.4 独立几何复核

Blender 5.2.2 后台工厂场景读取原始参考 OBJ：开放边、非流形边、朝向错误、退化面数量均为 0，正体积，非相邻三角形 BVH 相交候选数为 0。BVH 容差 1e-8、面面积阈值 1e-12，计算前平移到局部坐标。

该程序排除共享顶点的三角形对，故不是完整自交证明；没有通过这一检查来宣称 GT 的建筑语义或完整实体正确性。没有修改用户打开的 Blender 场景或参考几何。

## 3. 已完成的来源坐标整理

Point2Building 的原作者归一化点云与 Mesh 同时按 `source = normalized * author_scale + author_center` 还原。CRS 与高程基准尚未独立核准，不擅自标注米。PolyGNN mini 没有完整源坐标变换，保持作者归一化坐标。

各数据对提供 `points.xyz`、`gt.obj`、`wireframe.obj`、`provenance.json`。线框由 Mesh 提取结构边：边界/非流形边或相邻面法向夹角至少约 10°；排除共面三角化内部边，包含底部结构边。它是派生监督，不是独立人工线框标注。

## 4. 统一分析坐标，不使用 GT 确定变换

为了让早期采用绝对阈值的历史算法同时处理真实源坐标与仿真归一化坐标，固定一套可逆的分析坐标规范：

令输入点云各轴最小/最大值为 p_min、p_max，

`o = (p_min + p_max) / 2`

`s = ||p_max − p_min||₂ / 30`

`x_canonical = (x_source − o) / s`

`x_source = x_canonical * s + o`

- o、s 仅由输入 XYZ 计算，不由 Mesh、线框、地面真值、训练标签或预测结果计算。
- 点、GT Mesh 顶点和派生线框顶点应用同一个变换。不得独立归一化预测与 GT。
- 保留 Z 朝向，执行各向同性缩放和平移，不旋转、不做各轴独立缩放。
- 30 是预先固定的算法分析尺度，不是建筑实际大小的估计，也不是米。算法阈值必须注明“分析单位”。
- 保留全部有限输入点的数量、顺序；不去噪、不重采样、不降采样、不补点，不用参考底高给输入增强。
- 实例级包围盒对离群点敏感；本轮保留这一限制，不通过暗中过滤改善指标。
- 标准文件采用 float64 处理与高精度文本保存，重读后逆变换验证：点误差 ≤1e-8 源单位，Mesh/线框 ≤1e-5 源单位。
- 每个预测同时保存分析坐标 Mesh 和恢复源坐标的 OBJ/线框；展示平移不写回源坐标文件。

全 562 对的新版本位于 `dataset/processed/standardized_pairs_v001/`，不覆盖原始库及前期派生版本。全部标准化是数据准备；这不授权完整集运行重建。清单中只开放 starter78，其余训练432/测试130仍锁定。

v0.1.0 的历史原坐标复现保持不变；本次试验应命名为“v0.1.0 + 固定统一预处理”，避免把尺度转换收益误写成算法演化收益。两反馈组使用完全相同预处理。

## 5. 分组、重复与使用阶段

完整本地集合 562 对：真实 363、仿真199。项目训练432（真实312+仿真120），封存测试130（真实51+仿真79），原78入门包含在训练，不额外计数。

真实组：作者中心距离 ≤200 源单位连接空间组；精确 Mesh 哈希与顶点对距离相似（绝对容差0.05源单位、相对0.005）合并；有入门样例的组留训练，其余组按固定哈希选20%的组封存。实际训练/测试最近中心距205.8676源单位。作者合格test18全已入门，因此项目test51来自作者train。作者预训练权重可能见过它们。

## 6. 小试评测与论文表述

固定 `local-geometry-v1`：表面按面积随机采样10,000点、结构边按长度采样10,000点，seed739；CD/ECD是两方向最近邻欧氏距离均值的一半和，非平方；NC为双向采样对应法向绝对点积平均。包括边界和底面边。V/F比使用原多边形顶点/面计数，另记三角面数量。未完成官方一致性核准，所有官方字段留空。

主观测诊断使用全部原始输入点到预测表面的距离，不以删除困难点降低误差。逆向 Mesh→输入误差缺少可见性时不用于惩罚补全。评测器和协议在两个反馈条件间固定；源单位误差可由分析误差乘该样例 s 得到。跨真实/仿真分别汇报，不能混合物理量。

首轮是每组一个候选、一个种子的预算匹配试验，用于检验反馈传递、候选复测、接受/拒绝和经验迁移链路。记录候选次数、失败、耗时；模型内部 Token 与确切服务快照如无法取得须标记 unavailable，不伪造等Token控制。不能据此宣称统计显著或已完成论文 F0–F5、E1–E10 全矩阵。
