# 反馈、建筑知识与高度规则：v002 实现说明

日期：2026-09-21。本页解释已保存的反馈包、提议及代码，不把提议中的预期收益当作实验结果。范围只限固定 starter78：真实 Zurich 38、仿真 mini 40。完整训练432、封存测试130没有在本轮启用。

本轮有三项明确变化：外部文本反馈补充可定位的几何诊断；显式知识从 K01–K08 扩展为 K01–K09 并附 X01/X02；`full` 组在提议前获得并查看两张诊断拼图。三组候选均从同一 v0.1.0 起点独立提出。历史 v0.5.1 另作工程参考。

## 1. 初版八条知识分别是什么

初版机器可读原件为 `config/knowledge/rules.json`，版本 `building-knowledge-v001`。知识文件含适用条件、所需证据、反例和验证状态；写入规则不等于已经实现或证明它普遍有效。

| ID | 规则含义 | 对算法/报告的实际要求 | 适用边界与当前状态 |
|---|---|---|---|
| K01 | 保留有观测支持的凹轮廓；最小外接矩形只适合估计朝向 | 不能把矩形当作所有建筑的真实轮廓 | 稀疏离群点会误导边界；当前候选使用凸包，仍未实现凹角和庭院 |
| K02 | 每个平面需要局部支持范围；低附属屋顶不应压低整栋主屋顶 | 平面选取应考虑局部残差、相邻关系及支持区域 | 曲面不满足分片平面假设；当前仍主要使用单个凸体的全局下包络，局部台阶装配尚未实现 |
| K03 | 缺少回波不能证明空间为空；补全面必须明确标为推断 | 不按无点区域直接挖洞；墙面和底面需说明补全假设 | 只有可信扫描射线/可见性才能提供空域约束；目前缺扫描轨迹 |
| K04 | 闭合实体需要一致共边、正确绕序且无自交 | 检查开放边、非流形边、面绕序、退化面等 | 屋顶片不应被强制当闭合实体；完整预测自交检查尚未实现，因此不能声称完整实体有效性已证明 |
| K05 | 正交方向和垂直墙面是可被证据推翻的先验 | 有斜边观测时不应强迫全部直角 | 倾斜墙面、曲面、挑檐都是反例；垂直墙面仍是本轮补全假设 |
| K06 | 必须报告全部原始点的残差和局部失败 | 不靠删掉困难点改善分数；总均值不能证明完整性 | 已有全部输入点到表面诊断及失败记录；仍不能把拟合残差当 GT 准确率 |
| K07 | 结构边评估应去掉共面三角化产生的内部对角线 | 依据原多边形邻接与法向提取结构边，再算本地 ECD | 当前是 `local-geometry-v1` 协议；没有证明与比赛官方边定义一致 |
| K08 | 最低回波不能唯一确定地面或完整建筑高度 | 底高需要可信地面或明确不确定性标签 | 可信地面观测可提供约束；现有 q0.001 底面仅是观测补全假设 |

## 2. 上一轮更新了什么，没有更新什么

上一轮 `starter78-feedback-pilot/proposals/F0` 和 `F3` 读取相同初版八条知识。F0没有外部结果反馈，按 K01/K05 提出把稳健矩形内的 XY 支持替换为凸包；它没有实现凹轮廓。F3读取 discovery24 的结构化外部文本，针对“无屋顶平面支持”失败增加一次恢复：仅原平面提取失败后纳入 q25 高度并列点并降低支持下限。其目标是恢复失败样例，不承诺改善已成功样例的几何。

**上一轮规则库没有演化。** 新增内容写在 `meta/policy_evolved.json` 的反馈阅读顺序、提议要求和四条经验中，并未修改 K01–K08：

1. 失败后恢复能提高成功覆盖，但可能完全不改变原成功样例。
2. 几何算子能改善原成功样例，同时仍不能恢复整体失败。
3. 覆盖率和几何质量必须分别计数；共同成功集的配对比较与成功样例均值不能混用。
4. 拓扑通过不能证明几何准确，也不能单独决定哪个候选更好。

该策略要求先读失败，再读局部问题、几何指标和拓扑。它是如何组织下一次修改的经验假设，不是新的建筑几何规律。策略文本改变本身不证明递归改进。

**旧 F3 是结构化文本反馈，没有读取图像。** 旧实验的 Blender 渲染和后续诊断图片用于事后展示。它们不能证明图像参与过旧候选生成，也不能据旧 F0/F3 差异声称图像有效。当前 v002 从其中的 discovery 样例渲染选出图像，在本轮提议之前重新作为输入提供给 `full`。

距离在本轮统一 canonical 分析坐标下计算，不是米。预处理由输入包围盒中心和对角线确定，点/GT/预测使用同一可逆变换；不得独立归一化后比较。

`full` 的两张拼图分别包含真实和仿真 discovery 样例，每行显示输入、初始模型、开发参考Mesh及初始模型俯视图。示例按已授权discovery结果选取，包含较大误差或失败例，不能当作代表总体的随机抽样。它们是几何对照图，不是深度图/法向图或美学评分。

## 4. 显式知识 v002 新增哪些内容

`knowledge-v002.json`保留原八条规则，新增K09，并单列两条经验：

- **K09：坐标与高度。** 屋顶标高是Z坐标，立面高度是屋顶标高减去有依据的底高；输入bbox中心不定义地面。坐标关系是事实，检测阈值仍是待验证假设。拒绝无输入支持的高度修正时应保留原推理和不确定性，不能设置Z=0地面或按绝对Z钳制。
- **X01：失败恢复和轮廓改进解决不同问题。** 来自上一轮discovery24+selection24经验，可以分别设计算子；并不保证组合一定更好。
- **X02：经验策略变了，算法仍可能没有变好。** 一个分支可能从不触发，或没有解决支持不足；需要记录触发与外部复测，不能只看策略文字。

v002知识包是本轮版本化输入，初版`config/knowledge/rules.json`继续保留。新增高度审计的全78结果供用户审核；本轮候选设计只允许使用旧固定discovery24的当前反馈。上一轮已公开的discovery+selection经验属于X01的来源，因此本轮selection仍只能解释为适应性开发复测，不可声称从未用于开发的测试集。

## 6. 高度审计：Z与建筑高度不能混为一谈

定义共同坐标系下的屋顶标高`z_roof`和可信底高`z_base`，局部建筑高度为`h=z_roof-z_base`。倾斜地形或多层屋面下两者都可能随XY变化。参考Mesh的全局`max(Z)-min(Z)`只是一项总体高度统计，参考最低点也未必就是物理地面。

canonical定义是`z_c=(z_source-o_z)/s`。其中`o_z`是输入bbox中高，因而canonical零点不代表地面。Zurich可以恢复作者源坐标，但CRS/高程基准未独立核准；mini只能恢复作者归一化坐标。以下统计仅针对已筛选开发集，2%/5%为描述性误差带，不是可部署阈值。

| 审核项 | 真实38栋 | 仿真40栋 |
|---|---:|---:|
| 输入最低Z与参考底高绝对误差 / GT高度，中位数 | 37.75% | 1.51% |
| 最低回波高于参考底面超过2%高度 | 37/38 | 0/40 |
| 最低回波低于参考底面超过2%高度 | 0/38 | 15/40 |
| 输入最高Z与参考屋顶最高Z误差 / GT高度，中位数 | 4.55% | 3.51% |
| 输入q0.99与参考屋顶最高Z误差 / GT高度，中位数 | 2.95% | 1.35% |
| 输入PCA屋面候选q0.99与参考屋顶最高Z误差，中位数 | 3.29% | 1.25% |
| 输入Z全跨度 / GT高度，中位数 | 65.63% | 105.67% |

真实反例`point2building_04499_z4961a69d00000000`位于discovery：最低回波源Z为521.700012，参考底高512.128000，差占GT高度72.62%。仿真discovery反例`polygnn_mini_DEBY_LOD2_5092970`最低回波为−0.04807030，参考底高−0.04276242，低约6.21%建筑高度。两者分别说明缺底部观测和低端噪声都可能出现。

仅discovery24的真实12栋，最低回波全部高于参考底面超过2%高度，误差中位数51.77%；其PCA屋面候选q0.99误差中位数2.78%。仿真12栋对应为1.60%与1.06%。可靠屋面支持可以帮助核对屋顶标高，但不能补出从未观测到的真实底高。PCA候选本身只是输入几何启发式，没有逐点屋顶语义真值。

整体平移`t`使`o'=o+t、s'=s`，从而`(p+t-o')/s'=(p-o)/s`。坐标一致的高度差与局部残差不变，恢复后的预测应整体平移`t`。相反，按源坐标`Z<0`或`Z>某常数`判异常会因坐标原点改变而改变决定。78栋平移数值检查的最大canonical误差为3.60e−12；这是预处理检查，不是对三个完整算法平移等变性的实测证明。

建议的异常回退应依据输入支持：局部屋面残差、可靠支持覆盖、结构有效性，并使用输入尺度/噪声尺度表达容差。缺少可信底高时报告`ground_unobserved/base_assumed`；拒绝不受支持的新高度修正可保留冻结默认结果，但默认结果仍须保留不确定性，不能视为正确地面。

**本轮full没有实现完整的上述回退机制。** 它只在选中屋面某角点不高于`q0.001临时底面+1e−6`时，重新从在全部角点高于同一临时底面的候选平面中选择；没有可用平面就报错。该相对检查不受整体Z平移影响，但其临时底面依然未验证，`1e−6`也是分析坐标数值容差。它没有恢复真实地面，没有DTM，也没有“异常后自动调用旧默认算法”的完整分支。

完整逐栋Z极值、分位数、GT底高/屋顶高、canonical与源坐标、恢复原点及分区统计位于`work/experiments/2026-09-21/feedback-components-v002/height-audit/`下的`summary.json`、`per_building.csv`和`findings.md`。全78高度审核用于解释，不应回流成当前候选的selection/transfer反馈。

## 7. 当前消融能回答什么

本轮模型提议消融有三种条件：全量文本、全量文本加显式知识v002、全量文本加同一知识再加图像。`text_k`对`text_no_k`观察显式知识包的影响；`full`对`text_k`观察额外图像证据下的候选差异。

另有独立代码算子消融`height_guard_off`：以同一`full`候选为基础，仅关闭临时底面相对角点检查。它不是第四次模型提议；它与full的配对结果用于检查这一高度保护算子的实际贡献，不能解释为全部图像或知识的贡献。该独立运行已完成：78份OBJ与FULL逐字节一致，当前检查的可测贡献为0。

这不是完整六层逐项消融。分别去掉几何、法向、结构、拓扑的实验尚未执行；深度/法向栅格和完整预测自交检测也尚未实现。图像增加的信息不与文本严格等量，各组精确Token预算不可得，每组只有一个候选，且候选同时修改多个算子。因此即便复测有差异，也不能宣称统计因果、稳定的知识增益、独立图像贡献或完整递归自我改进。

结果必须分真实/仿真、discovery/selection/transfer报告，另记失败恢复、新增失败、共同成功样例配对指标、拓扑和兼容修复成本。不能只比较变化了分母的成功样例平均值。已完成本轮运行：T兼容版77/78输出、76/78当前拓扑通过；TK和FULL均78/78输出且当前拓扑通过；v0.5.1为76/78输出、28/78当前拓扑通过。FULL相对TK共同成功样本平均ΔCD/ΔECD：真实−0.033374/−0.074108，仿真−0.080656/−0.217885，单位为分析坐标。它是单候选观察结果，不能称为图像的因果贡献。全部原始指标、失败、配对差值及限制见[最终报告](../reports/2026-09-21-feedback-components-v002/index.html)和[实验记录](../experiments/2026-09-21/feedback-components-v002/summary.md)。

v0.5.1是既有人工工程演进版本，独立运行在同一78对、同一输入统一预处理和固定本地评测下，用于了解当前小步候选与已有工程方法的差距。它不是本轮候选的父版本，也不能把其过去累积的改进算成当前Harness的收益。
